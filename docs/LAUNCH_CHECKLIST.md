# Launch checklist

## Core gameplay
- [ ] New player understands the rule within 10 seconds.
- [ ] First meaningful scare/chaos event occurs early.
- [ ] Each checkpoint is readable on mobile.
- [ ] Death reliably increases Wake.
- [ ] Wake transitions visibly alter the experience.
- [ ] 100% Wake creates a memorable final chase.
- [ ] Finish cannot be exploited by skipping checkpoints.

## Art
- [ ] Final Happy model replaces fallback blockout.
- [ ] No visible rig collapse or clipping.
- [ ] Walk/run/crawl silhouettes read clearly on phone.
- [ ] Jumpscare timing feels intentional rather than random.
- [ ] Playplace has original signage and visual identity.
- [ ] Lighting remains readable during blackout events.

## Monetization
- [ ] All pass IDs configured.
- [ ] All developer product IDs configured.
- [ ] Purchases grant exactly once.
- [ ] Repeat purchases are idempotent.
- [ ] Free players can complete the game.
- [ ] UI clearly labels what each purchase does.

## Reliability
- [ ] 1-player test passes.
- [ ] 4-player test passes.
- [ ] 12-player stress test passes.
- [ ] Rejoin restores profile.
- [ ] Disconnect during purchase is safe.
- [ ] Mobile UI fits common phone aspect ratios.
- [ ] No recurring Output errors.

## Viral-content pass
- [ ] 0→100% Wake transformation is visually obvious.
- [ ] At least 8 events produce clip-worthy reactions.
- [ ] Monster has at least 3 recognizable behaviors.
- [ ] A viewer can understand a gameplay clip without narration.
